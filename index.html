Documentary Studio

A personal desktop application for producing long-form documentary videos.

Documentary Studio is a single-user Windows application, run locally by its author, that assembles long-form documentary videos and publishes them to the author's own YouTube channel. It is not a hosted service, it is not distributed to other people, and it has no users other than its author.

What it does

The application runs a production pipeline end to end on one machine. Each stage hands its output to the next:

  • drafting a narration script from a written outline;
  • generating the voice-over from that script;
  • generating and upscaling the still images that illustrate each chapter;
  • rendering the finished video from the audio and the images;
  • generating a thumbnail;
  • uploading the finished video, with its title, description and tags, to the author's own YouTube channel.

Use of YouTube API Services

The final stage of the pipeline uses YouTube API Services to upload finished videos. The application uploads only to the channel of the person who signs in, and it does not read, collect or process any other person's YouTube data.

Videos produced with this application are published to a single channel: The Soft Constant.
